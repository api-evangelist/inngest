Inngest has launched official tooling for coding agents like Claude Code, Codex, and Cursor to help developers build durable infrastructure directly within their workflow. The offering includes skills that teach agents how to write Inngest code and a dev-server connection allowing agents to inspect and test functions locally. The company emphasizes that these tools integrate seamlessly with agents developers already use, ensuring generated code includes proper retry logic, idempotency, and flow control that matches their installed version.
